# E-COMMERCE-ANALYSIS

# Project Overview
An end-to-end data analysis project focused on exploring e-commerce sales, customer purchasing behaviour, product performance, payment methods, and delivery performance.

The project uses SQL, Python, and Power BI to analyse e-commerce data and present meaningful business insights through an interactive dashboard.

# Tools & Technologies

SQL (MySQL): Data querying, aggregation, and analysis

Python: Data cleaning and exploratory data analysis

Pandas: Data manipulation and preprocessing

Power BI: Data visualization and dashboard creation

# Project Workflow
Data Cleaning: Cleaned the raw dataset using Python and Pandas.

SQL Analysis: Performed queries to analyse sales, orders, customers, product categories, and delivery performance.

Data Visualization: Created an interactive Power BI dashboard to present key metrics and trends.

# Key Analysis Areas
Total Revenue and Total Orders

Total Customers and Average Order Value

Monthly Revenue and Order Trends

Top Performing Product Categories

State-wise Revenue Analysis

Payment Method Distribution
